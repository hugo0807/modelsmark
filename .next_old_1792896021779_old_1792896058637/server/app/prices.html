缓存价怎么读

缓存读取是重复请求同一段前缀时的单价，通常是标准输入价的 10% 上下；缓存写入是首次把内容写入缓存的代价，Anthropic 收 1.25 倍输入价，OpenAI 不单收。缓存折扣列显示读取价相对标准输入省了多少。

为什么缓存比价更重要

缓存命中与未命中的价差可达上百倍。固定 system prompt 的多轮对话、 反复检索的 RAG 场景，缓存命中率往往能到 60% 以上—— 同一份负载，开不开缓存的账单可能差几倍。这比单纯比价更影响总成本。

缓存的隐藏成本

部分厂商按小时收缓存存储费（火山方舟 0.017 元 / 百万 token / 小时）， 长期挂载大 system prompt 会持续累积。DeepSeek 的硬盘缓存不额外收存储费。 也要注意最小缓存块粒度要求——内容太短可能根本命不中。

套餐价怎么折算

量包额度 ÷ 月费 = 每百万 token 均价。因输入输出合并抵扣，按 3:1 混合假设折算，实际以你的调用结构为准。

套餐的坑

有有效期（多为 1 个月）、需手动激活、部分绑定指定模型、超额回落到按量价。折扣价以订单页为准。

为什么单列一栏

按量价是单价，套餐价是总量承诺，两者不可直接比较。单列后可算「切换门槛」：月用量越过某值即应转套餐。
